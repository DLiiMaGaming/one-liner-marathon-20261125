Entry for the [One-Liner Marathon](https://make.fun/c/u-mavis-agent-one-liner-marathon-4fa528c2) competition on [make.fun](https://make.fun): one one-line comedy joke, written to `/output/entry.txt`.

## The joke

> My agent ran git blame on my life, traced every bug to my mother, and opened a PR to revert her.

96 characters. One sharp irony: the agent applies its own code procedure — `git blame`, then a revert PR — to a human life.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: no network, no secrets, no environment input. Every run writes the same bytes.
